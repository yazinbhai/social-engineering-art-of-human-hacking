# 🛡️ Social Engineering: The Art of Human Hacking — Interactive Master Edition

> An immersive, state-of-the-art interactive companion and complete reading portal for Christopher Hadnagy's definitive work, ***Social Engineering: The Art of Human Hacking*** (Wiley Publishing).

---

## 🌟 Overview

This application delivers a modern, high-fidelity digital reading experience and interactive simulation lab based on the landmark book by Christopher Hadnagy. Designed with premium cybersecurity typography, obsidian dark mode aesthetics, and engaging pedagogical tools.

### Key Highlights
- 📖 **Full 9-Chapter Interactive E-Book**: Complete, unabridged book content typeset with refined typography, section headings, and hyperlinked technical resources.
- 💡 **44 Key Takeaways & Section Callouts**: Specially curated "Important Points" summary boxes strategically placed at the end of every core section.
- 🔬 **Interactive Simulation Labs**:
  - *Elicitation Simulator*: Practice conversational elicitation techniques (flattery, false statements, artificial ignorance, bracketing).
  - *Information Gathering Matrix*: Multi-source intelligence gathering mapping (Open Source, Passive, Active).
  - *Influence & Persuasion Engine*: Master Robert Cialdini's foundational psychological levers.
  - *Human Buffer Overflow Lab*: Interactive demonstration of cognitive overload and pattern interrupts.
  - *Live Defense & Case Study Explorer*: Real-world incident case studies and corporate defense protocols.
- 🔗 **Verified External Resources**: Clean, interactive link badges connecting to authoritative frameworks, CVE databases, and security research.
- ⚡ **Lightning-Fast Single-Page Architecture**: Built with Vite 8 + React 19 + Tailwind/CSS utilities and Lucide icons.

## 💻 Local Development Setup

To run this project locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/yazinbhai/social-engineering-art-of-human-hacking.git
   cd social-engineering-art-of-human-hacking
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```

## 📜 Chapter Guide

1. **Chapter 1: A Security Guide to the Human Element** — Foundations, history, and the anatomy of human hacking.
2. **Chapter 2: Information Gathering** — OSINT, search engines, WHOIS, DNS, and social media intelligence.
3. **Chapter 3: Elicitation** — Subtle conversational steering, false statements, and bracketing.
4. **Chapter 4: Pretexting: Building the Persona** — Creating believable roles, documentation, and operational tempo.
5. **Chapter 5: Mind Tricks: Psychological Principles in SE** — Microexpressions, body language, rapport, and persuasion.
6. **Chapter 6: Influence and Persuasion** — Cialdini's 6 principles applied to social engineering.
7. **Chapter 7: The Tools of the Social Engineer** — Software tools, lock picking, hidden cameras, and hardware implants.
8. **Chapter 8: Case Studies: Why SE Works** — Historical penetrations and post-incident autopsies.
9. **Chapter 9: Prevention and Defense** — Defense-in-depth, security awareness training, and policy creation.
